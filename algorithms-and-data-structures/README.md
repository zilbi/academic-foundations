# Algorithms and Data Structures

This section presents the main topics I studied in the university course **Algorithms and Data Structures**, along with selected problems.

* Basic algorithm design techniques
* Correctness proofs
* Time and memory complexity
* Worst-case and average-case analysis
* Asymptotic notation
* Recurrence relations for algorithm analysis
* Lower bounds and comparison-based arguments
* Choosing algorithms under practical constraints

* Stacks and queues
* Linked structures

* Hash tables
* Disjoint set union
* Sparse tables
* Prefix sums and difference arrays

* Comparison-based sorting algorithms
